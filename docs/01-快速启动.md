# 01 - 快速启动

> *"最好的开始方式是开始。第二好的方式是看别人怎么开始。"*

---

## 前置条件

- Node.js 18+（推荐 20 LTS）
- npm 9+
- 一个 API Key（DeepSeek / OpenAI / 任意 OpenAI 兼容接口）
- 如果在国内：一个代理（可选，但强烈推荐）

## Step 1: 安装

```bash
npm install -g openclaw
```

验证安装：
```bash
openclaw --version
```

## Step 2: 初始化

```bash
openclaw init
```

这会在 `~/.openclaw/` 下创建以下结构：

```
~/.openclaw/
├── openclaw.json          # 核心配置文件（所有配置都在这里）
├── workspace/             # 工作区（AI 的"家"目录）
│   ├── AGENTS.md          # AI 行为规范
│   ├── SOUL.md            # AI 性格定义
│   ├── USER.md            # 用户画像
│   ├── MEMORY.md          # 记忆索引
│   ├── TOOLS.md           # 工具配置笔记
│   ├── memory/            # 记忆详情目录
│   ├── skills/            # 技能目录
│   └── scripts/           # 自定义脚本
├── extensions/            # 插件目录
└── agents/                # 会话日志
```

## Step 3: 配置模型

编辑 `~/.openclaw/openclaw.json`，找到 `models.providers`，添加你的 API：

```jsonc
{
  "models": {
    "mode": "merge",
    "providers": {
      "deepseek": {
        "timeoutSeconds": 300,
        "baseUrl": "https://api.deepseek.com",
        "api": "openai-completions",
        "apiKey": "sk-your-deepseek-api-key",
        "models": [
          {
            "id": "deepseek-chat",
            "contextWindow": 1000000,
            "maxTokens": 384000,
            "input": ["text"]
          }
        ]
      }
    }
  }
}
```

**关键字段说明：**

| 字段 | 含义 | 示例 |
|:-----|:-----|:-----|
| `baseUrl` | API 端点 | `https://api.deepseek.com` |
| `api` | API 协议 | `openai-completions`（绝大多数模型都用这个） |
| `apiKey` | 你的密钥 | `sk-xxxx` |
| `contextWindow` | 上下文窗口大小 | `1000000`（100万 tokens） |
| `maxTokens` | 单次最大输出 | `384000` |

## Step 4: 设置默认模型

在 `agents.defaults.model` 里指定：

```jsonc
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "deepseek/deepseek-chat",
        "fallbacks": ["deepseek/deepseek-reasoner"]
      }
    }
  }
}
```

**primary** 是默认模型，**fallbacks** 是备选（primary 挂了自动切换）。

## Step 5: 启动

```bash
openclaw gateway start
```

启动后：
- 控制面板：`http://localhost:18789`
- CLI 对话：`openclaw chat`
- 状态检查：`openclaw status`

## Step 6: 第一次对话

```bash
openclaw chat
```

输入 `你好`，如果收到回复——恭喜，你的 AI 活了。

---

## 常见问题

### Q: 启动后没有回复？

1. 检查 API Key 是否正确
2. 检查网络是否能访问 API 端点
3. 查看日志：`openclaw gateway logs`

### Q: 控制面板打不开？

默认只监听 `localhost`。如果需要远程访问，修改 `gateway.controlUi.allowedOrigins`。

### Q: 模型报错 "context window exceeded"？

检查 `contextWindow` 是否设对了。DeepSeek V4 是 1M，别设成 4K。
