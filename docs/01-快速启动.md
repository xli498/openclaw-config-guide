# 01 - 快速启动

> *"最好的开始方式是开始。第二好的方式是看别人怎么开始。"*

---

## 适用范围

本章使用当前运行时状态和官方 schema 作为最终依据。不要因为其他章节或旧截图出现 YAML/JSON 路径，就覆盖你本机的现有配置。

## 前置条件

- Node.js 22.22.3+ / 24.15+ / 25.9+（官方系统要求，推荐 Node 26；旧版 18/20 已不满足）
- npm 12+（11.16+ 亦可）
- 一个 API Key（DeepSeek / OpenAI / 任意 OpenAI 兼容接口）
- 如果在国内：一个代理（可选，但强烈推荐）

## Step 1: 安装

macOS / Linux 官方推荐一键脚本：

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

或用 npm（新版 npm 需带 `--allow-scripts`）：

```bash
npm install -g openclaw@latest --allow-scripts=openclaw
```

验证安装：
```bash
openclaw --version
```

## Step 2: 初始化

```bash
openclaw setup
```

> 官方 CLI 无 `init` 顶层命令（`init` 只存在于 `plugins init` 等子命令）；引导式初始化用 `openclaw setup`，密钥配置可配合 `openclaw onboard`。

这会在 `~/.openclaw/` 下创建以下结构：

```
~/.openclaw/
├── openclaw.json          # 核心配置文件（所有配置都在这里）
├── workspace/             # 工作区（AI 的"家"目录）
│   ├── AGENTS.md          # AI 行为规范
│   ├── SOUL.md            # AI 性格定义
│   ├── IDENTITY.md        # 身份描述（官方 bootstrap 文件）
│   ├── USER.md            # 用户画像
│   ├── BOOTSTRAP.md       # 引导说明（官方 bootstrap 文件）
│   ├── MEMORY.md          # 记忆索引（记忆体系由 memory-core 插件管理）
│   ├── TOOLS.md           # 工具配置笔记（个人约定，非官方 bootstrap 文件）
│   ├── memory/            # 记忆详情目录
│   ├── skills/            # 技能目录
│   └── scripts/           # 自定义脚本
├── extensions/            # 插件目录
└── agents/                # 会话日志
```

## Step 3: 配置模型

> **注意（2026-08 核对）**：DeepSeek 在新版本 OpenClaw 中是插件式 provider。若下方手写配置不生效，先安装官方插件并重启 Gateway：`openclaw plugins install @openclaw/deepseek-provider`。也可以直接用引导命令完成密钥配置：`openclaw onboard --auth-choice deepseek-api-key`。

编辑 `~/.openclaw/openclaw.json`，找到 `models.providers`，添加你的 API：

```jsonc
{
  "models": {
    "mode": "merge",
    "providers": {
      "deepseek": {
        "timeoutSeconds": 300,
        "baseUrl": "https://api.deepseek.com",
        "api": "openai-completions",
        "apiKey": "${DEEPSEEK_API_KEY}",
        "models": [
          {
            "id": "deepseek-v4-flash",
            "contextWindow": 1000000,
            "maxTokens": 384000,
            "input": ["text"]
          }
        ]
      }
    }
  }
}
```

**关键字段说明：**

| 字段 | 含义 | 示例 |
|:-----|:-----|:-----|
| `baseUrl` | API 端点 | `https://api.deepseek.com` |
| `api` | API 协议 | `openai-completions`（绝大多数模型都用这个） |
| `apiKey` | 你的密钥 | `${DEEPSEEK_API_KEY}` |
| `contextWindow` | 上下文窗口大小 | `1000000`（100万 tokens） |
| `maxTokens` | 单次最大输出 | `384000` |

## Step 4: 设置默认模型

在 `agents.defaults.model` 里指定：

```jsonc
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "deepseek/deepseek-v4-flash",
        "fallbacks": ["deepseek/deepseek-v4-pro"]
      }
    }
  }
}
```

**primary** 是默认模型，**fallbacks** 是备选（primary 挂了自动切换）。

## Step 5: 检查与启动

先检查状态：

```bash
openclaw status
```

Gateway 未运行时，再按当前版本的官方启动方式启动。已经运行时不要重复启动；配置变更后先做最小验证，再判断是否需要重载或重启。

验证：

```bash
openclaw status
```

> 控制面板端口、CLI 子命令与服务行为可能随版本变化；以本机输出和官方文档为准。

## Step 6: 第一次对话

```bash
openclaw chat
```

输入 `你好`，如果收到回复——恭喜，你的 AI 活了。

## 常见问题

### Q: 启动后没有回复？

1. 检查 API Key 是否正确
2. 检查网络是否能访问 API 端点
3. 查看日志：`openclaw logs`

### Q: 控制面板打不开？

默认只监听 `localhost`。如果需要远程访问，修改 `gateway.controlUi.allowedOrigins`。

### Q: 模型报错 "context window exceeded"？

检查 `contextWindow` 是否设对了。DeepSeek V4 是 1M，别设成 4K。
