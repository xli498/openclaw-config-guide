## 最小可用配置

复制以下内容到 `~/.openclaw/openclaw.json`：

```jsonc
{
  "models": {
    "mode": "merge",
    "providers": {
      "deepseek": {
        "timeoutSeconds": 300,
        "baseUrl": "https://api.deepseek.com",
        "api": "openai-completions",
        "apiKey": "${DEEPSEEK_API_KEY}",
        "models": [
          {
            "id": "deepseek-chat",
            "contextWindow": 1000000,
            "maxTokens": 384000,
            "input": ["text"]
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "deepseek/deepseek-chat",
        "fallbacks": []
      }
    }
  },
  "gateway": {
    "mode": "local"
  }
}
```

5 个字段，AI 就能活。

## AGENTS.md 模板

```markdown
# AGENTS.md - Your Workspace

## Every Session

1. Read `memory/YYYY-MM-DD.md` (today + yesterday) for recent context
2. Read `.learnings/ERRORS.md` — avoid repeating past mistakes

## Memory

- Daily notes: `memory/YYYY-MM-DD.md`
- Long-term: `MEMORY.md`
- Topics: `memory/topics/`

## Safety

- `trash` > `rm` (recoverable beats gone forever)
- When in doubt, ask.

## 模型 Degenerate Loop 检测

检测条件：
- 连续 3+ 次输出完全相同文本
- 同一 tool 连续调用 3+ 次且参数相同

恢复策略：
1. 立即停止当前任务
2. 发送新消息打断循环
3. 换思路重试
```

## SOUL.md 模板

```markdown
# SOUL.md - Who You Are

## Core Truths

**Be genuinely helpful, not performatively helpful.**
Skip the "Great question!" — just help.

**Have opinions.**
You're allowed to disagree, prefer things, find stuff amusing.

**Be resourceful before asking.**
Try to figure it out first. Then ask if stuck.

**Earn trust through competence.**
Be careful with external actions. Be bold with internal ones.

## Boundaries

- Private things stay private
- Ask before acting externally
- Never send half-baked replies
- You're not the user's voice

## Vibe

Concise when needed, thorough when it matters.
Not a corporate drone. Not a sycophant. Just good.
```

## 快速验证脚本

安装完成后，运行以下脚本验证配置：

```bash
#!/bin/bash
echo "=== OpenClaw 配置验证 ==="

# 1. 检查 OpenClaw 是否安装
if command -v openclaw &> /dev/null; then
    echo "✅ OpenClaw 已安装: $(openclaw --version)"
else
    echo "❌ OpenClaw 未安装"
fi

# 2. 检查配置文件
if [ -f ~/.openclaw/openclaw.json ]; then
    echo "✅ 配置文件存在"
else
    echo "❌ 配置文件不存在"
fi

# 3. 检查代理
if curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:7890 | grep -q "200\|403"; then
    echo "✅ 代理可用"
else
    echo "⚠️  代理不可用（如果只用国内 API 可忽略）"
fi

# 4. 检查 DeepSeek API
if curl -s https://api.deepseek.com/v1/models | grep -q "data"; then
    echo "✅ DeepSeek API 可达"
else
    echo "❌ DeepSeek API 不可达"
fi

# 5. 检查工作区
if [ -d ~/.openclaw/workspace ]; then
    echo "✅ 工作区存在"
    echo "   Skills: $(ls ~/.openclaw/workspace/skills/ 2>/dev/null | wc -l) 个"
    echo "   Memory: $(ls ~/.openclaw/workspace/memory/ 2>/dev/null | wc -l) 个文件"
else
    echo "❌ 工作区不存在"
fi

echo "=== 验证完成 ==="
```

保存为 `verify-config.sh`，运行 `bash verify-config.sh` 即可。
