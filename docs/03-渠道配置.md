# 03 - 渠道配置

> *"产品再好，用户用不到等于零。渠道就是你的火箭发射台。"*

---

## 渠道概览

OpenClaw 支持多种聊天渠道，让你的 AI 可以通过微信、QQ、Telegram 等工具与你对话。

| 渠道 | 类型 | 难度 | 稳定性 |
|:-----|:-----|:-----|:-------|
| 小艺渠道 | 华为原生 | ⭐ 最简单 | ⭐⭐⭐⭐⭐ |
| 微信 | 网页版登录 | ⭐⭐ 简单 | ⭐⭐⭐ |
| QQ Bot | 官方 API | ⭐⭐⭐ 中等 | ⭐⭐⭐⭐ |
| Telegram | Bot API | ⭐⭐ 简单 | ⭐⭐⭐⭐⭐ |

## 小艺渠道（推荐新手）

### 为什么推荐？
- 华为原生集成，开箱即用
- 不需要额外申请 API
- 支持语音、图片等多模态

### 配置

```jsonc
{
  "channels": {
    "xiaoyi-channel": {
      "wsUrl1": "wss://celia-claw-drcn.ai.dbankcloud.cn/openclaw/v1/xiaoyi/ws/link",
      "wsUrl2": "wss://celia-claw-drcn.ai.dbankcloud.cn/openclaw/v1/xiaoyi/ws/link",
      "apiKey": "SK-your-xiaoyi-key",
      "agentId": "your-agent-id",
      "apiId": "your-api-id",
      "uid": "your-uid",
      "enabled": true,
      "fileUploadUrl": "https://celia-claw-drcn.ai.dbankcloud.cn"
    }
  }
}
```

### 如何获取这些参数？

1. 注册华为开发者账号
2. 在小艺开放平台创建应用
3. 获取 API Key、Agent ID、UID
4. 填入配置即可

## 微信渠道

### 配置

```jsonc
{
  "channels": {
    "openclaw-weixin": {
      "enabled": true
    }
  },
  "plugins": {
    "entries": {
      "openclaw-weixin": {
        "enabled": true
      }
    }
  }
}
```

### 登录流程

1. 启动 OpenClaw
2. 控制台会显示一个二维码
3. 用微信扫码登录（需要微信网页版权限）
4. 登录成功后自动保持连接

### ⚠️ 注意事项

- 微信网页版可能被封号，建议用小号
- 部分微信账号没有网页版权限
- 连接可能断开，OpenClaw 会自动重连

## QQ Bot 渠道

### 配置

```jsonc
{
  "channels": {
    "qqbot": {
      "appId": "your-app-id",
      "clientSecret": "your-client-secret",
      "enabled": true,
      "model": {
        "primary": "deepseek/deepseek-chat",
        "fallbacks": ["deepseek/deepseek-reasoner"],
        "maxTokens": 64000,
        "timeoutSeconds": 300
      }
    }
  },
  "plugins": {
    "entries": {
      "openclaw-qqbot": {
        "enabled": true
      }
    }
  }
}
```

### 如何获取 QQ Bot 参数？

1. 访问 [QQ 开放平台](https://q.qq.com)
2. 创建机器人应用
3. 获取 App ID 和 Client Secret
4. 配置机器人权限和事件订阅

### TTS（语音消息）

QQ Bot 支持发送语音消息，需要配置 TTS：

```jsonc
{
  "channels": {
    "qqbot": {
      "tts": {
        "provider": "edge-tts",
        "model": "tts-1",
        "voice": "alloy"
      }
    }
  }
}
```

需要安装 `edge-tts`：
```bash
pip install edge-tts
```

### 图片服务器

QQ Bot 发送图片需要一个公网可访问的图片服务器：

```jsonc
{
  "channels": {
    "qqbot": {
      "imageServerBaseUrl": "https://your-image-server.com"
    }
  }
}
```

如果在内网，可以用 SSH 反向隧道：
```bash
ssh -R 80:localhost:18765 nokey@localhost.run
```

## 渠道级模型配置

每个渠道可以独立配置模型，互不影响：

```jsonc
{
  "channels": {
    "qqbot": {
      "model": {
        "primary": "minimax/MiniMax-M3",
        "fallbacks": ["xiaomimimo/mimo-v2.5-pro", "deepseek/deepseek-chat"]
      }
    },
    "openclaw-weixin": {
      "model": {
        "primary": "minimax/MiniMax-M3",
        "fallbacks": ["xiaomimimo/mimo-v2.5-pro"]
      }
    }
  }
}
```

**用途**：
- QQ Bot 用便宜模型（消息量大）
- 微信用好模型（重要对话）
- 小艺渠道用默认模型

## Bindings（渠道绑定）

Bindings 决定哪个渠道的消息由哪个 Agent 处理：

```jsonc
{
  "bindings": [
    {
      "agentId": "channel-bot",
      "match": { "channel": "qqbot" }
    },
    {
      "agentId": "channel-bot",
      "match": { "channel": "openclaw-weixin" }
    }
  ]
}
```

如果不配置 bindings，所有渠道的消息都由默认 Agent 处理。

## 实战建议

### 新手推荐
先配**小艺渠道**，零门槛，5 分钟搞定。

### 进阶推荐
小艺 + 微信双渠道，日常用小艺，重要对话用微信。

### 重度用户
三个渠道全开，不同渠道用不同模型，按需分配。
