# 06 - 技能系统

> *"OpenClaw 本身只是个大脑。Skills 才是它的手、脚和眼睛。"*

---

## Skills 是什么？

Skills 是 OpenClaw 的能力扩展系统。每个 Skill 是一个目录，包含：
- `SKILL.md` — 技能说明和使用指南
- 可能包含脚本、配置、模板等

OpenClaw 启动时会自动加载所有 Skills，AI 可以根据任务自动选择合适的 Skill。

---

## 安装 Skills

### 方式一：官方 CLI（推荐）

```bash
# 搜索
openclaw skills search "web search"

# 安装（社区包可能需要 --acknowledge-clawhub-risk）
openclaw skills install @owner/<slug>
```

> 独立 `clawhub` CLI（npm 包存在）主要负责 uninstall/login/publish/sync 等操作；安装/搜索用 `openclaw skills` 子命令即可。

### 方式二：受控手动安装

不要直接 clone 到正式 Skills 目录。正确流程是：

```text
下载到临时目录
→ 阅读 SKILL.md、脚本与依赖
→ 安全审计（含网络、文件、凭证和外部执行边界）
→ 通过后安装到正式 Skills 目录
→ 验证 Skill 被正常加载
```

> 安全审计服务可能上传候选 Skill 包；含私有代码或凭证的目录不要直接提交审计。

### 方式三：对话内安装

部分版本支持在对话中让 AI 搜索并安装技能；是否可用以当前版本官方文档为准。

## Skills 配置

在 `openclaw.json` 中配置 Skills 加载路径：

```jsonc
{
  "skills": {
    "limits": {
      "maxSkillsPromptChars": 30000
    },
    "load": {
      "extraDirs": [
        "~/.openclaw/workspace/skills/"
      ],
      "watch": true
    }
  }
}
```

| 参数 | 含义 | 建议值 |
|:-----|:-----|:------|
| `maxSkillsPromptChars` | Skills 描述的最大字符数 | 30000（太多会占用上下文） |
| `watch` | 是否监视 Skills 目录变化 | true（新增 Skill 自动加载） |
| `extraDirs` | 额外的 Skills 目录 | 按需添加 |

## 创建自己的 Skill

### 最小 Skill 结构

```
my-skill/
└── SKILL.md
```

### SKILL.md 模板

```markdown
---
name: my-skill
description: "一句话描述这个技能做什么"
---

# My Skill

## 功能
描述这个技能的功能。

## 使用方法
当用户说 XXX 时，执行 YYY。

## 步骤
1. 第一步
2. 第二步
3. 第三步

## 注意事项
- 注意点 1
- 注意点 2
```

### 带脚本的 Skill

```
my-skill/
├── SKILL.md
├── scripts/
│   └── do_something.sh
└── templates/
    └── output.md
```

## Skill 安全

⚠️ **重要**：安装任何新 Skill 前，必须经过安全扫描。

OpenClaw 内置了 `skill-scope` 安全检查：
- 扫描 Skill 目录中的可疑代码
- 检查是否有外部网络请求
- 检查是否有文件系统越权访问

如果你手动安装 Skill，建议先检查 `SKILL.md` 和脚本内容。
