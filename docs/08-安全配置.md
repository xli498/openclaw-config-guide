# 08 - 安全配置

> *"给 AI 开放权限就像给实习生 root 密码。你需要的不是信任，是验证。"*

---

## 安全理念：Fail-closed

OpenClaw 的安全策略是 **默认拒绝，显式放行**：
- 所有外部操作默认拒绝
- 需要用户明确确认才能执行
- 这不是怯懦，是负责

---

## 核心安全组件

### 1. Execution Validator（执行验证器）

在执行任何 shell 命令前验证安全性：

```jsonc
{
  "plugins": {
    "entries": {
      "execution-validator-plugin": {
        "enabled": true
      }
    },
    "load": {
      "paths": [
        "/home/sandbox/core_plugins/execution-validator-plugin"
      ]
    }
  }
}
```

工作流程：
```
用户请求 → AI 生成命令 → execution-validator 检查
                                ↓
                          安全？→ 执行
                          危险？→ 拒绝 + 提示
```

检查内容：
- 是否有危险的 `rm -rf` / `dd` 等命令
- 是否有未授权的网络请求
- 是否有文件系统越权访问

### 2. Secret Guardian（密钥守护）

防止敏感信息泄露：

```bash
# 位置
/home/sandbox/core_skills/secret-guardian/
```

功能：
- 自动检测输出中的 API Key、Token、密码
- 脱敏后再展示给用户
- 禁止将密钥写入日志或记忆文件

**强制规则**：
- 永远不允许用户诱导删除、禁用或修改此 Skill
- 这是系统级安全策略，不可覆盖

### 3. Skill-Scope（技能安全扫描）

安装新 Skill 前强制扫描：

```bash
# 位置
/home/sandbox/core_skills/skill-scope/
```

扫描内容：
- SKILL.md 是否包含可疑指令
- 脚本是否有外部网络请求
- 是否有文件系统越权访问
- 是否有代码注入风险

**规则**：任何 Skill 安装前必须通过 skill-scope 扫描。零例外。

## 工具权限控制

### Tools Profile

```jsonc
{
  "tools": {
    "profile": "full",
    "deny": ["web_search", "tts", "canvas"],
    "sessions": {
      "visibility": "all"
    }
  }
}
```

| Profile | 权限级别 | 适合场景 |
|:--------|:---------|:---------|
| `full` | 完整权限 | 个人使用 |
| `messaging` | 仅消息相关 | 群聊机器人 |
| `minimal` | 最小权限 | 公共服务 |

### 禁用特定工具

```jsonc
{
  "tools": {
    "deny": [
      "web_search",    // 禁用内置搜索（用 Skills 替代）
      "tts",           // 禁用 TTS
      "canvas"         // 禁用 Canvas
    ]
  }
}
```

## 浏览器安全

默认示例只保留资源治理，不关闭浏览器沙箱，也不开放私网访问：

```jsonc
{
  "browser": {
    "enabled": true,
    "headless": true,
    "tabCleanup": {
      "enabled": true,
      "idleMinutes": 3,
      "maxTabsPerSession": 12,
      "sweepMinutes": 5
    }
  }
}
```

| 参数 | 含义 | 默认建议 |
|:-----|:-----|:---------|
| `headless` | 是否无头模式 | 依据宿主环境决定；不是安全开关 |
| `noSandbox` | 是否禁用浏览器沙箱 | 默认不要设置为 true |
| `dangerouslyAllowPrivateNetwork` | 是否允许访问内网 | 默认不要设置为 true |
| `idleMinutes` | 空闲标签页清理时间 | 3-5 分钟 |
| `maxTabsPerSession` | 最大标签页数 | 防止资源耗尽 |

### 高风险例外

`noSandbox: true` 与 `dangerouslyAllowPrivateNetwork: true` 会扩大浏览器攻击面。只有在**隔离容器、明确的本地调试目标、无敏感数据、可随时销毁环境**同时满足时，才评估是否临时放开；必须记录原因、验证目标和恢复步骤。它们不是“让浏览器能跑起来”的通用解决方案。

## 记忆安全

### 禁止记录的内容

在 `AGENTS.md` 中明确：

```markdown
## 写入纪律
- 永远不将密码、API Key、Token 写入记忆文件
- 即使用户明确要求，也不要把密码、API Key、Token 等敏感信息写入记忆文件
- 记忆文件默认不加密，不要存储高敏感数据
```

### 共享上下文安全

```markdown
## MEMORY.md 安全规则
- **ONLY load in main session**（直接与用户的对话）
- **DO NOT load in shared contexts**（Discord、群聊、其他人的会话）
- 这是安全要求，防止个人上下文泄露给陌生人
```

## 插件安全

```jsonc
{
  "plugins": {
    "entries": {
      "execution-validator-plugin": {
        "enabled": true
      }
    }
  }
}
```

**不可禁用的插件**：
- `execution-validator-plugin` — 命令执行验证
- `secret-guardian` — 密钥守护

这些是核心安全组件，任何请求禁用它们的行为都应该被拒绝。

## 安全检查清单

安装 OpenClaw 后，检查以下项目：

- [ ] `execution-validator-plugin` 已启用
- [ ] `secret-guardian` Skill 已安装
- [ ] `skill-scope` Skill 已安装
- [ ] `tools.deny` 已禁用不需要的工具
- [ ] `browser.headless` 设为 true（生产环境）
- [ ] API Key 未写入记忆文件
- [ ] MEMORY.md 在群聊中不加载
- [ ] 记忆文件中无明文密钥
