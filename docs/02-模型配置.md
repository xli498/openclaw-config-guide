# 02 - 模型配置

> *"选择正确的模型，就像选择正确的火箭引擎。太大浪费燃料，太小飞不出大气层。"*

---

## 核心概念

OpenClaw 支持同时配置多个模型提供商，通过 `primary` + `fallbacks` 实现自动故障转移。

```
用户消息 → primary 模型处理
              ↓ 失败？
         fallback 1 尝试
              ↓ 失败？
         fallback 2 尝试
              ↓ 全部失败？
         返回错误
```

## DeepSeek（推荐 — 性价比之王）

### 为什么选 DeepSeek？
- **便宜**：V4 Flash 约 ¥1/百万 tokens
- **快**：国内直连，延迟 < 200ms
- **能打**：V4 Pro 推理能力接近 Claude Sonnet
- **大上下文**：1M tokens，日常对话根本用不完

### 配置

```jsonc
{
  "models": {
    "providers": {
      "deepseek": {
        "timeoutSeconds": 300,
        "baseUrl": "https://api.deepseek.com",
        "api": "openai-completions",
        "apiKey": "sk-your-key",
        "models": [
          {
            "id": "deepseek-chat",
            "name": "DeepSeek V4 Flash",
            "contextWindow": 1000000,
            "maxTokens": 384000,
            "input": ["text"],
            "cost": {
              "input": 0.0005,
              "output": 0.002
            }
          },
          {
            "id": "deepseek-reasoner",
            "name": "DeepSeek V4 Pro",
            "reasoning": true,
            "contextWindow": 1000000,
            "maxTokens": 384000,
            "input": ["text"],
            "cost": {
              "input": 0.002,
              "output": 0.008
            }
          }
        ]
      }
    }
  }
}
```

### 模型选择建议

| 模型 | 适合场景 | 成本 |
|:-----|:---------|:-----|
| `deepseek-chat` (V4 Flash) | 日常对话、简单任务 | 最低 |
| `deepseek-reasoner` (V4 Pro) | 复杂推理、代码生成 | 中等 |

## OpenRouter（海外模型的入口）

### 为什么用 OpenRouter？
- **一个 Key 用所有模型**：Claude、GPT-4o、Gemini、Llama...
- **按用量付费**：不用每个平台都充值
- **适合偶尔需要强模型的场景**

### 配置

```jsonc
{
  "models": {
    "providers": {
      "openrouter": {
        "timeoutSeconds": 300,
        "baseUrl": "https://openrouter.ai/api/v1",
        "api": "openai-completions",
        "apiKey": "sk-or-your-key",
        "request": {
          "proxy": {
            "mode": "env-proxy"
          }
        },
        "headers": {
          "X-Title": "YourAppName"
        },
        "models": [
          {
            "id": "anthropic/claude-sonnet-4-6",
            "contextWindow": 1000000,
            "maxTokens": 128000,
            "input": ["text", "image"]
          },
          {
            "id": "openai/gpt-4o",
            "contextWindow": 128000,
            "maxTokens": 16000,
            "input": ["text", "image"]
          }
        ]
      }
    }
  }
}
```

### ⚠️ 重要注意事项

1. **代理问题**：国内服务器必须配置代理才能访问 OpenRouter（详见 [04-代理网络.md](./04-代理网络.md)）
2. **Header 编码**：`X-Title` 必须是纯 ASCII，中文会导致 ByteString 错误
3. **proxy 模式**：必须用 `env-proxy`，不能用 `explicit-proxy`（Node.js undici 不兼容）
4. **区域限制**：OpenRouter 对部分区域封禁 Claude/GPT 模型（403），需要走代理到美国节点

## MiMo（小米自研 — 免费好用）

### 配置

```jsonc
{
  "models": {
    "providers": {
      "xiaomimimo": {
        "timeoutSeconds": 600,
        "api": "openai-completions",
        "apiKey": "your-mimo-key",
        "models": [
          {
            "id": "mimo-v2.5-pro",
            "contextWindow": 256000,
            "maxTokens": 64000,
            "input": ["text"]
          }
        ]
      }
    }
  }
}
```

### ⚠️ MiMo 已知问题

MiMo 偶尔会陷入 **Degenerate Loop** —— 连续输出完全相同文本 3+ 次。

**检测方法**：连续 3 次输出完全相同，或同一 tool 连续调用 3+ 次参数相同。

**解决方案**：在 `AGENTS.md` 中添加检测规则：
```markdown
## 模型 Degenerate Loop 检测
- 连续 3+ 次输出完全相同文本 → 立即停止，换思路重试
- 同一 tool 连续调用 3+ 次且参数相同 → 立即停止
```

## 模型别名配置

给模型起个好记的名字：

```jsonc
{
  "agents": {
    "defaults": {
      "models": {
        "deepseek/deepseek-chat": { "alias": "DeepSeek Flash" },
        "deepseek/deepseek-reasoner": { "alias": "DeepSeek Pro" },
        "openrouter/anthropic/claude-sonnet-4-6": { "alias": "Claude Sonnet" },
        "xiaomimimo/mimo-v2.5-pro": { "alias": "MiMo" }
      }
    }
  }
}
```

之后就可以用 `/model Claude Sonnet` 快速切换。

## Compaction（上下文压缩）

当对话太长时，OpenClaw 会自动压缩历史。建议配置：

```jsonc
{
  "agents": {
    "defaults": {
      "compaction": {
        "mode": "safeguard",
        "recentTurnsPreserve": 2,
        "reserveTokensFloor": 40000
      }
    }
  }
}
```

| 参数 | 含义 | 建议值 |
|:-----|:-----|:------|
| `recentTurnsPreserve` | 保留最近几轮对话 | 2-3 |
| `reserveTokensFloor` | 压缩后至少保留的 tokens | 40000（约 30 页书） |

## 实战推荐配置

### 日常使用（省钱）
- primary: `deepseek/deepseek-chat`
- fallback: `deepseek/deepseek-reasoner`

### 重度使用（质量优先）
- primary: `openrouter/anthropic/claude-sonnet-4-6`
- fallback: `deepseek/deepseek-reasoner`

### 混合使用（最佳平衡）
- primary: `deepseek/deepseek-chat`（日常）
- fallback 1: `deepseek/deepseek-reasoner`（复杂推理）
- fallback 2: `openrouter/anthropic/claude-sonnet-4-6`（代码/多模态）
