# 07 — 多渠道配置实战

## 概述

OpenClaw 支持同时配置多个渠道（Channel），允许一个 Agent 实例通过多种方式与用户交互。本文基于微信 + QQ Bot 双渠道的真实部署经验。

## 双渠道架构

```
┌──────────────────────────────────────────┐
│            OpenClaw Gateway               │
│                                            │
│  ┌──────────┐  ┌──────────┐  ┌────────┐  │
│  │ WeChat   │  │ QQ Bot   │  │ Web    │  │
│  │ Channel  │  │ Channel  │  │ UI     │  │
│  └────┬─────┘  └────┬─────┘  └───┬────┘  │
│       │             │            │        │
│  ┌────▼─────────────▼────────────▼─────┐  │
│  │         Agent (default)             │  │
│  │    model: deepseek/deepseek-v4-pro  │  │
│  └──────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

## 微信渠道配置

### 前置条件

1. 微信企业号/服务号
2. 微信公众平台配置回调 URL
3. Token 和 EncodingAESKey

### 完整配置

```yaml
channels:
  - id: wechat
    name: "微信助手"
    type: weixin
    config:
      appId: "wx**"
      appSecret: "***"
      token: "***"
      encodingAESKey: "***"
      callbackUrl: "https://your-domain.com/wechat/callback"

    # 消息处理
    deduplicateWindow: 5000       # 5 秒去重窗口
    maxMessageLength: 600         # 单条回复最大长度（字符）
    splitLongMessage: true        # 自动拆分长消息

    # 图片处理
    imageServer: "https://your-domain.com/images"
    maxImageSize: 2097152         # 2MB

    # 关联的 agent
    defaultAgent: default
```

### 微信消息格式限制

| 限制项 | 数值 |
|--------|------|
| 文本消息最大长度 | 2048 字符 |
| 图片最大尺寸 | 2MB |
| 每天主动推送次数 | 取决于账号类型 |
| 回复超时 | 5 秒（被动回复） |

**重要**：微信的被动回复模式下，必须在 5 秒内返回。超时后微信会重发消息（导致重复回复问题）。建议：

```yaml
channels:
  - id: wechat
    config:
      replyMode: "async"          # 异步回复模式
      acknowledgeTimeout: 3000    # 3 秒内确认收悉
```

## QQ Bot 渠道配置

### 前置条件

1. QQ Bot AppId 和 Token
2. QQ 开放平台注册应用

### 完整配置

```yaml
channels:
  - id: qqbot
    name: "QQ 助手"
    type: qqbot
    config:
      appId: 1903992323          # QQ Bot AppId
      appSecret: "***"
      token: "***"

    # 消息处理
    deduplicateWindow: 5000
    maxMessageLength: 2000       # QQ 消息限制更宽松

    # 图片处理
    imageServer: "https://your-domain.com/images"

    defaultAgent: default
```

### QQ Bot 消息渲染特点

与微信不同，QQ Bot 的 Markdown 渲染能力有限：

| 格式 | 微信 | QQ Bot |
|------|------|--------|
| 纯 URL（独立行） | ✅ 可点击 | ✅ 可点击 |
| 内联 URL | ✅ 可点击 | ❌ 纯文本 |
| 图片 | ✅ 显示 | ✅ 显示 |
| Markdown 表格 | ✅ | ⚠️ 部分支持 |
| 代码块 | ✅ | ⚠️ 格式不完整 |
| 嵌套列表 | ✅ | ❌ 不支持 |

#### URL 渲染问题

QQ Bot 只将**独立行的纯 URL**渲染为可点击链接。内联 URL（如 `查看详情：https://...`）保持纯文本。

**适配方案**：在发送前处理 URL，确保在独立行：

```python
def qq_url_formatter(text: str) -> str:
    """Ensure URLs are on separate lines for QQ Bot."""
    import re
    urls = re.findall(r'https?://[^\s)>]+', text)
    for url in urls:
        if not re.search(rf'(^|\n){re.escape(url)}($|\n)', text):
            text = text.replace(url, f'\n{url}\n')
    return re.sub(r'\n{3,}', '\n\n', text).strip()
```

## 双渠道共用 Agent

### 配置

```yaml
# 渠道配置
channels:
  - id: wechat
    name: "微信助手"
    type: weixin
    config:
      appId: "wx**"
      # ...
    defaultAgent: default

  - id: qqbot
    name: "QQ 助手"
    type: qqbot
    config:
      appId: 1903992323
      # ...
    defaultAgent: default

# Agent 配置（两个渠道共用）
agents:
  default:
    model: deepseek/deepseek-v4-pro
    systemPrompt: |
      你是一个智能助手，支持微信和 QQ 两个渠道。
      注意 QQ Bot 的消息渲染限制：URL 放在独立行。
```

### 渠道感知

为了让 Agent 知道当前消息来自哪个渠道，在 System Prompt 中注入渠道信息：

```yaml
agents:
  default:
    systemPrompt: |
      你是一个智能助手。当前通过 {{channelName}} 渠道与用户交互。
      {{#if channelName == "QQ 助手"}}
      QQ Bot 消息规则：
      - URL 必须放在独立行才能渲染为链接
      - 不支持嵌套列表和复杂表格
      {{/if}}
```

## 图片服务配置

### 独立图片服务器

```yaml
# openclaw.yaml
imageServer:
  baseUrl: "https://your-domain.com/images"
  storagePath: "/var/www/images"
  maxFileSize: 2097152       # 2MB
  allowedTypes:
    - image/png
    - image/jpeg
    - image/gif
    - image/webp
```

### Nginx 配置

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    location /images/ {
        alias /var/www/images/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

## TTS 代理配置

### 场景

需要使用 edge-tts（微软文字转语音）但需要代理。

### 架构

```
OpenClaw → Edge TTS Proxy (Python, port 5050) → Microsoft TTS API
                 ↓
          Mihomo Proxy (127.0.0.1:7890)
```

### 启动 TTS 代理

```bash
# 安装
pip install edge-tts fastapi uvicorn

# 代理脚本
cat > /usr/local/bin/tts_proxy.py <<'PYEOF'
import asyncio
import edge_tts
from fastapi import FastAPI, HTTPException
from fastapi.responses import StreamingResponse
import io
import os

app = FastAPI()

# 代理配置
PROXY = os.environ.get("HTTP_PROXY", "http://127.0.0.1:7890")

@app.post("/v1/audio/speech")
async def text_to_speech(request: dict):
    text = request.get("input", "")
    voice = request.get("voice", "zh-CN-XiaoxiaoNeural")
    rate = request.get("speed", "+0%")

    if not text:
        raise HTTPException(status_code=400, detail="Missing 'input'")

    try:
        communicate = edge_tts.Communicate(text, voice, rate=rate,
                                           proxy=PROXY)
        audio_data = io.BytesIO()
        async for chunk in communicate.stream():
            if chunk["type"] == "audio":
                audio_data.write(chunk["data"])

        audio_data.seek(0)
        return StreamingResponse(
            audio_data,
            media_type="audio/mpeg",
            headers={"Content-Disposition": "attachment; filename=speech.mp3"}
        )
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=5050)
PYEOF

# systemd 服务
cat > /etc/systemd/system/tts-proxy.service <<'EOF'
[Unit]
Description=Edge TTS Proxy
After=network.target

[Service]
Type=simple
User=sandbox
Environment="HTTP_PROXY=http://127.0.0.1:7890"
Environment="HTTPS_PROXY=http://127.0.0.1:7890"
ExecStart=/usr/bin/python3 /usr/local/bin/tts_proxy.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now tts-proxy
```

### OpenClaw TTS 配置

```yaml
tts:
  provider: custom
  endpoint: "http://127.0.0.1:5050/v1/audio/speech"
  voice: "zh-CN-XiaoxiaoNeural"
  speed: "+10%"
```
